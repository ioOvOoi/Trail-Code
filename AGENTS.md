## Agent skills

### Issue tracker

Issues live as markdown files in this repo under `.scratch/<feature-slug>/` (local markdown tracker, no external service). See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the five canonical default labels as-is: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` + `docs/adr/` at the repo root, created lazily — proceed silently when absent. See `docs/agents/domain.md`.
